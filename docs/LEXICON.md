# Lexicon

The working vocabulary for pattern-buffer. One name per concept, used identically in code, docs, tests, and specs. A term not in this file is added here before it is used twice.

## The two rules

1. **The double-read test.** Every exported name (class, function, CLI command) must parse correctly for an engineer with zero Star Trek context. Canon homage that only works as fan service stays out of the code and lives in doc prose.
2. **Nouns carry the flavor; verbs stay boring.** The operation algebra (`set`, `relate`, `event`, `resolve`, `retract`, `merge`, `refer`) and the role matrix (Ingestor, Classifier, Resolver, Projector, Renderer) keep plain engineering names — they are authority boundaries and must be instantly legible.

## Working terms (code symbols)

| Term | Definition | Double-read |
|---|---|---|
| **`World`** | The named, individual unit: one PatternBuffer + its physics (resolution policy + decay configuration) + derived indexes. The thing hosts bind to, name, and ship. | Universal. |
| **`PatternBuffer`** | The append-only assertion log — the only truth (P1). Each World owns exactly one; a buffer never holds two worlds; a world never spans two buffers (the 1:1 invariant). `world_id` is lineage/identity; the file is the buffer instance — never-joined playthrough forks may share a `world_id` (whitepaper A5). | Trek: holds the pattern between materializations. Systems: a buffer of patterns (cf. protocol buffers). |
| **`materialize()` / `Materialization`** | The projector's read: `(scope, as_of, frame, lens, budget)` → the world served from pattern. | Trek: rematerialization — re-entry exactly as left. Databases: a materialized view is the canonical term for a derived, disposable projection over a log. Both readings are precisely correct. |
| **`neighborhood()`** | A bounded read around one entity: folded subject state plus identity-closed structural neighbors across containment, lateral, relation, and event axes. The event axis reads **event records** as of the read (EVENTS-ONE-READER-V1 §6): an event whose record has an `agent`/`patient` row resolving to the entity, and the causes its record names — a closed or zero-duration event stays reachable once it has occurred. | Plain graph/search vocabulary; kept bounded, not a query language. |
| **`part_of` / composition axis** | The compositional structural relation (PLACE-FEATURE-ABSTRACTION-V1) — a burrow `part_of` a hillside, a desk `part_of` an office. A **separate axis from containment**: composition is constitutive structure (the part doesn't move out), containment (`in`) is movable location. A core structural predicate, classified CONSTITUTIVE, valid-timed (dug/boarded); a relating edge for identity (evidence against), never a containment merge-veto. `locate`/`contents`/`route` ignore it. | Plain (mereology: part-of-the-whole). |
| **`composition()` / `features()`** | The two compositional reads, mirroring `locate`/`contents` on the `part_of` axis: `composition(e)` walks the chain up (the entity's place-in-the-structure); `features(p)` returns the `part_of`-children (a place's sub-features). A sub-place is **one entity** answering both the place lens (locate/contents/route/state) and the feature lens (these) — structural retrieval-invariance, the compositional sibling of AKA's identity union. Both **halt on a conflicted parent** — never silently pick. | Plain. |
| **`ResolveRequest` / `task_request()`** | What a `patternbuffer_resolve` call is for, as data (RESOLVE-REQUEST-V1): world, entity, aspect, kind, the inherited standing facts and the placeholder's own constraints (exactly the prompt's constraint lines), `as_of`, frame, policy. V1.1 adds `current`: the entity's own folded STATE facts as of `as_of`, such as an age or a haircut, for code generators only; never in the prompt. V1.2 adds `existing` (below). It rides on the call's schema object (`TaskSchema`, a dict that serializes byte-identically), so a code generator answers without parsing prose; `task_request(schema)` reads it, None on any other call. | Plain. |
| **`existing`** | On `ResolveRequest` (RESOLVE-REQUEST-V1.2, WORN-OBJECTS-V1): for a minting aspect, the items already joined to the entity by its relation at the placeholder's time, as `(id, kind-or-None, sorted names)` sorted by id, every field read in the resolve's frame at that valid time, from the log as it stands at the force; the generator answers the complement. `()` for `contents` and for every non-minting aspect. | Plain. |
| **minting aspect** | An aspect whose resolution mints entities joined to the resolved entity by a containment relation (`contents` → `in`, `attire` → `worn_by`), instead of writing literal rows on one key (WORN-OBJECTS-V1 §1; the table is `MINTING_ASPECTS`). A minted item is `obj:gen_N` with a generated `kind`, `name` and edge, and optionally generated look rows for the declared aspects its kind carries. | Plain. |
| **attire** | The minting aspect for what a person wears (WORN-OBJECTS-V1). Its garments are entities `worn_by` the person, so they can be taken off, stolen or found. A world opts in with `attr:attire · resolvable_for · person`. | Plain. |
| **anchor row** | A `name` or `alias` row with a string value and a status other than `generated` (`IdentityRegistry._is_anchor_row`, WORN-OBJECTS-V1 §4): the only rows any identity-evidence collector reads. Invention is never evidence that two things are one; `refer` and `by_alias` still find an invented thing by its name. | Plain. |
| **`salience()`** | A derived projection-time ranking score used to order neighborhoods and budgeted materializations. It never changes validity and is never stored as truth. | Plain attention/retrieval vocabulary. |
| **`aggregate()`** | A bounded collection rollup: `sum`, `count`, `min`, `max`, or `avg` over numeric folded values on a container's `contents()`, optionally recursive. | Plain analytics vocabulary; computed from present facts, never stored. |
| **`confidence()`** | A derived trust score for one functional folded key: `provenance × recency × corroboration` (halved if conflicted). **Corroboration counts distinct agreeing source-class identities, not proven-independent origins** (SOURCE-IDENTITY-V1 §5): the engine holds no attribution graph, and undeclared-origin rows pool, so read it as *how many distinctly-attributed sources agree*. **Recency is mode-scoped (TRACKING-MODE-V1):** permanent in fiction/deny worlds (the page is true — story-time liveness is `salience`'s axis, not trust's); in tracking worlds it decays with **unconfirmed wall time** under the declared `DecayPolicy`, with fail-closed `unconfigured`/`unconfirmed` null branches (excluded + renormalized, never faked). Payload carries `recency`, `recency_status`, `last_confirmed_at_wallclock` (the "last confirmed June 19" join; null in fiction) beside `last_observed_at` (valid-time, both modes). `frame` may be a list — trust over the read-union (`knows:O ∪ public`). Validity untouched; never stored (the membrane). | Plain; the temporal-trust sibling of `salience` (relevance). |
| **source class** | The identity of *who or what attests* an assertion, derived read-side by `source_class` and the unit of two contracts: fold **supersession** (automatic only *within* a class — across classes a disagreement raises the §7.2 truth-maintenance flag and an ask, never a silent last-write-wins) and **corroboration**'s de-duplicated count. **A source class is a source, not a category (SOURCE-IDENTITY-V1):** `document:doc:<id>` and `speaker:person:<id>` each carry their *identity*, so two distinct documents corroborate when they agree and flag when they differ, exactly as two speakers do — "a speaker is a document that talks" cuts both ways. Rows with no declared `source` pool into the single `direct` class (the **undeclared-origin** case — deliberate, and an open crossroads: SOURCE-IDENTITY-V1 §6). Multi-source rows classify deterministically: `doc:` outranks `person:`, lexicographically least within a kind. | Plain evidentiary sense of "source"; the qualifier *class* is the fold's grouping key. |
| **`DecayPolicy` / `decay_halflife_seconds`** | Tracking-world time physics as declared, rebuildable data (TRACKING-MODE-V1): `attr:<key> · decay_halflife_seconds · <finite positive n>` rows, resolved exact-authored-attribute → `attr:in` (the public containment-family subject) → `attr:__world__`. Read fresh at each read (current-physics-over-history); malformed declarations skip-receipt at the gate. Deliberately separate from `AttributeSemantics` — decay is physics, not fold semantics. Selects on `policy == "observe_or_unknown"` only, never `stance` (the no-bias invariant: the engine never judges what can exist, in either stance — skepticism is structural, from conflict and corroboration, never ontological). | Plain (radioactive half-life). |
| **world physics row** / `resolution_policy` | `attr:__world__ · resolution_policy · <policy>` (READ-SURFACE-V1 §7): the world's resolution policy, persisted. Canon, timeless, `stated`, CONSTITUTIVE, beside the world's decay default; written once by `World` (at genesis, or on a pre-existing world's first explicit-`policy=` open) and immutable — the gate refuses an item addressing it, `retract` refuses it, and the buffer admits one per log. Every open runs under it; an explicit `policy=` that disagrees raises `WorldPhysicsMismatch`. "One file plus its policy row" (whitepaper §16), literally. | Plain (a world's laws of nature, written down). |
| **`situation` lens** | A `materialize`/`snapshot` lens for re-entry: the standing-truth fold ∪ only the **live** events anchored to the scope, with closed history dropped. The middle path between `current_state` (no events) and `what_happened` (all events). The live events are emitted as their **event records** (EVENTS-ONE-READER-V1 §5): an event's own rows, classified or not, never its identity edges; a live "event" with no event rows (a `caused_by` naming a person) emits nothing. Derived every read, nothing stored. | Plain; "what's the situation here" reads in fiction and reality alike. |
| **live thread** | An event still worth surfacing on re-entry: one with an **open thread** (an unresolved winner with no `resolved_by`) **or** a **surviving effect** (a state it produced still un-superseded). The exhaustive partition of engine-knowable present relevance — a settled current fact or an open current question; anything else is host judgment. Anchored by where the live effect sits (walk back via `caused_by`), never by who participated. Computed, never stored; "dead" means "left no surviving effect," so suppressing it is correct, not lossy. A live thread surfaces as its **event record** (EVENTS-ONE-READER-V1). | Plain. |
| **event row** | A row whose stored subject is an `event:` id and whose value type is not `delta` (`is_event_row`, EVENTS-ONE-READER-V1 §1): exactly the rows the classifier's guardrail makes EVENT because of their subject. It **never folds**, classified or not — the fold drops it by structure, so an event is never inside a container and its keys fold to nothing before a sweep as after it. An accrue `delta` on an event is not one and still folds. | Plain. |
| **event record** / `event_records()` | An event's rows minus the engine's machinery (identity edges, provenance, semantics declarations): what kind of occurrence it was, who and what took part, when — **read, never folded** (EVENTS-ONE-READER-V1). `Indexes.event_records(frame, ids=, valid_as_of=, asserted_as_of=)` is the one reader: the visible event rows grouped by **resolved** id, without the sidecar. **The as-of rule:** an event has occurred by `T` when it has no stamped row or its earliest stamped row is at or before `T`; its record as of `T` is its timeless rows plus its rows stamped by then; `valid_to` never hides an event row. **The pick**, for every single value read from a record: the top evidence rank, then the greatest recency key. `events()`, `in_transit()`, `state()` on an event, the `what_happened`/`situation` lenses and `neighborhood()`'s event edges all read records. | Plain (an occurrence's record). |
| **`Degradation`** | The named failure class: served state contradicting the buffer — drift, contradiction, mutated canon. The test suite's core negative assertion is "no degradation." | Trek: buffer/holomatrix degradation. Systems: data degradation. |
| **`Frame`** | Perspective scope on every assertion: `canon`, `knows:<entity>`, named frames. Carries knowledge, contested truth, and privacy by structural absence. Identity is canon's, never perspectival (every frame resolves ids through the one canon closure), while names and aliases stay in the frame that said them (FRAME-SCOPED-IDENTITY-V1). | RDF named-graph heritage; kept plain deliberately. |
| **`who_knows()`** | The computed inverse of `frame_diff` (WHO-KNOWS-INVERSE-V1): given a fact `(entity, attribute[, value])`, the `knows:*` observer frames that **know** it — a frame qualifies iff its fold serves a concrete value (a frame holding only an unresolved placeholder does not know) and, given a value, the *folded value* matches it (READ-SURFACE-V1 §5): identity-aware; for a set-valued key, any current member; for an accrue key, the total. One predicate, `Indexes.fold_matches`, shared with `state(value=)["matches"]`. Derived from the frames that exist, never a stored `known_by` edge (which would breach the membrane); folded-not-raw, so a superseded/retracted belief drops. | Plain (the "who is aware of X" transpose). |
| **skip receipt** | A typed record (`SkipRecord`: entity, attribute, value, a fixed `reason` code, optional `detail`) of one item the ingest gate refused without raising; listed in `Receipt.skipped` (or `AtomicAbort.skipped`, where any skip aborts the set). The gate never normalizes a bad item into a guess: it skips and says why (GATE-AUTHORITY-V1 §0). | Plain (a receipt for what was not taken). |
| **mechanism attribute** | An attribute whose rows the engine writes *about* other rows rather than to state world facts: they operate on those rows or record what the gate did to them (`retracts`, `resolved_by`, `canonicalized_from`, `learned_at_wallclock`, `decided_by`, `representative`, `source_valid_from`, `correction_proposal`). Each has one owning component and is recognized by its owner's mark (status, subject shape), never by name alone; refused as ingest items (GATE-AUTHORITY-V1 §1). | Plain. |
| **bookkeeping attribute** | An attribute the engine writes to keep its own books rather than to state a world fact: every name in `META_ATTRIBUTES \| MECHANISM_ATTRIBUTES` (identity edges, receipts, retractions, provenance), read from the model module at call time (FACTS-BOOKKEEPING-V1). Wider than **mechanism attribute**. `facts(..., bookkeeping=False)` leaves their rows out, so a host scanning a frame for evidence holds no list of its own. `durability` is not one: it is a domain word too. | Plain. |
| **`decided_by`** | Who decided an identity merge, one row on the `identity_merge` event (IDENTITY-ROOT-CAUSES-V1 §3): `host` (the porcelain `merge`, `confirm`, `retype(absorb=)`), `statement` (a raw `same_as` item submitted through the ingest gate — an item's `same_as` key only proposes — with `extracted · true` beside it when it came from prose extraction) or `engine` (`reconcile`, promotion, `adjudicate_deferred`). A mechanism attribute: status mark `inferred`, refused as an item, honored only on an event the identity registry marked. Merges written before it derive the value from the evidence prefix at read time; `unknown` counts as `engine`. | Plain. |
| **representative designation** | A host merge naming which member of its closure the closure is served under (IDENTITY-REPRESENTATIVE-V1): `merge(a, b, evidence, representative=)`, `confirm(a, b, representative=)`, or implicitly `retype(absorb=target)`. It is one timeless `inferred` row, `event:merge_N · representative · <id>`, on a host-decided `identity_merge` event, and `representative` is a mechanism attribute (refused as an item). The closure's **representative** (what `resolve` returns, and every Receipt's `canonical_id`) is the id named by the latest honoured designation, else the first-seen member. Retracting a row the designation needs withdraws it. | Plain (the member that stands for the group). |
| **re-point event** | The four-row event a designated `merge`, `confirm` or `retype(absorb=)` writes on a pair that is already one closure (IDENTITY-REPRESENTATIVE-V1 §1a): `kind · identity_merge`, `evidence`, `decided_by · host`, `representative`, all timeless and `inferred`, with no `same_as` and no `caused_by`. It changes who the closure is served as and nothing else; the Receipt stays `noop_already_merged` and gains `repointed: true`. Retracting its `kind` or `representative` row withdraws it. | Plain (point the group at a different member). |
| **name-like anchor** | A `name` or `alias` that may count as identity evidence for an automatic merge (IDENTITY-ROOT-CAUSES-V1 §1): at most five **raw words** (`_anchor_words`: articles and honorifics counted) and not opening with a speaker-relative possessive (`_RELATIVE_POSSESSIVES`: my, our, your, his, her, their, its). A sentence or "my apprentice" is description, not identity: it stays a lookup alias, but fuses nothing. | Plain. |
| **settled apart** | A pair whose closures a retracted `same_as` edge once joined (IDENTITY-ROOT-CAUSES-V1 §2): the retraction recorded a decision that they are not one thing, so the automatic paths neither merge nor re-propose them. A host `merge` or `confirm` can still re-decide. Read through `retracted_targets`; derived per log version, never stored. | Plain. |
| **`canonical_attribute()`** | The one function that names an attribute (READ-SURFACE-V1 §3): the gate's normalization (strip, lowercase, spaces to `_`) and its forward alias map (built-ins, replayed receipts, runtime aliases), skipped for a structural attribute — `"Located In"` → `in`, `type` → `kind`. Applied on write by the gate and on read to every porcelain argument that names an attribute, so the fold key never fragments on either side; payloads echo the stored name. Inverse spellings (`holds`, `wearing`) are not renamed. On `Ingestor`, `World` and the porcelain. | Plain. |
| **`Thunk`** | An explicitly unresolved aspect with a resolution policy. Forced exactly once; memoized forever. Thunks can move without resolving. | CS-canonical (lazy evaluation). |
| **`deny` thunk** | The *established-unknowable* state of the unknown: an `unresolved` aspect whose policy refuses resolution, carrying a reason. A positive assertion that a thing is canonically unknown (the mystery box). Distinct from an absent row (unestablished) and a stored tag (a membrane breach). | Plain. |
| **relational absence** | The doctrine (whitepaper A6) that the unknown is never stored or inferred — only the computed gap between two populations of present facts, across **frames** (`frame_diff`; the N-observer knowledge lattice) and **time** (freshness = `now − t`). | Plain. |
| **membrane-test** | The guard: *could the engine recompute this row from other present facts? then it is derived and must never be stored — only an irreducible observation may be a fact.* Sibling to RFC-001's rejection-test. | Plain (cell membrane: derived stays out of the log). |
| **`frontier`** | The explicitly-unresolved region: the thunk table plus everything below the resolution floor. Where nothing has been established, the system serves no invented detail. | Robotics-canonical (occupancy-grid mapping); heritage is the lidar ingestion parallel. |
| **`delta`** | A `value_type` for a signed numeric increment. It is admitted like any other row and only folds into totals for attributes declared `accrue`. | Plain math/database vocabulary. |
| **`accrue`** | A fold policy for fungible quantities: latest absolute numeric baseline plus later signed deltas. | Accounting-canonical. |
| **`quantity` / `ledger`** | The derived numeric total / the append-only rows that produced it. Totals surface through `FoldResult.quantity` and `Materialization.quantities`; the ledger remains ordinary assertions. | Plain accounting. |
| **fold policy** (`by_class` / `last_write` / `accrue`) | Which row of a functional key the fold serves (READ-SURFACE-V1 §2). **`by_class`** — internal, the default for every undeclared attribute: the fold by durability class (CONSTITUTIVE earliest-wins, STATE ∪ DISPOSITIONAL by rank, source class and recency, with the §7.2 flag), never declarable. **`last_write`** — declared: the latest row by `(valid_from, asserted_at)` among the top evidence rank, whatever its durability; never conflicted, no source classes; functional attributes outside the containment family only. **`accrue`** — declared: baseline plus later deltas (above). `move` is no longer declarable; the containment family's cross-source move rule is keyed on `relation_family`. | Plain (how a key folds). |
| **durability pin** | A host's declared durability class for its own attribute (READ-SURFACE-V1 §1): `attr:<name> · durability · STATE \| DISPOSITIONAL \| CONSTITUTIVE` (never `EVENT` — occurrence stays structural), from `attribute_default` or a manual `attr:` row, never an item hint. The classifier reads it after its structural guardrails (`event:`, `name`/`alias`, META, the physics row, a placeholder) and before `structural` and the model, so a pinned row is never model-judged; accrual promotion skips it. Declare before data; a pin a guardrail would pre-empt, or a non-CONSTITUTIVE pin beside `structural: true`, skips `invalid_semantics_declaration`. Orthogonal to the fold policy: the pin picks the class, the policy the served row. Undeclared vocabulary stays per-row and model-judged. `durability` is not a META attribute: as a domain word (a sword's durability) it folds like any other. | Plain (a pinned value). |
| **`resolvable_for`** | A host's declaration that the resolver may invent an aspect for a kind of entity (RESOLVE-UNMARKED-V1): set-valued `attr:<aspect> · resolvable_for · <kind>`, one row per kind, from `attribute_default` or a manual `attr:` row, never an item hint. Read as `AttributeSemantics.resolvable_kinds(aspect)`. It opens nothing by itself: a world with no such row resolves exactly as before, and a declaration on a core attribute skips `invalid_semantics_declaration`. It folds nothing, so existing data on the aspect does not lock it. | Plain. |
| **`WorldService`** | The one host of a world for every module (WORLD-SERVICE-V1), in `patternbuffer.service` and outside the engine core. `attach(world, view_frame, perceptible=)` binds it to a World the host opened; `pump()` runs queued owner jobs on the host's thread and refreshes the viewer snapshot; `detach()` comes before any close, swap or copy; `session(name, role)` is a client's door. Viewers read; a recorder (standalone runner only) also records; an **author session** also writes, hosted or standalone. | Plain. |
| **author session** | A service session (`session(name, role="author")`, or `--author NAME` on the runner; AUTHOR-RECORD-V1) whose `record(items, at=, frame=)` writes canon (the default) or one character's `knows:<observer>` frame **outside the player's view**, each item once, as `stated`. A frame in the view's scope (the view frame, plus what `frame_scope` adds) is refused; so is any other frame name, and a handle as an id. The answer is the recorder's bare `recorded` / `refused`. Holds every viewer verb and no canon read. Contrast **recorder**: play events, written to canon and the view frame as `observed`. | Plain (the author is who states the world's truth). |
| **`World.snapshot()`** | A read-only World built normally over an in-memory backup of the owner's connection, then sealed: every append, the gate, retraction and every unit raise `ReadOnlyWorld`. Its derived sidecars stay writable; the source's file and `data_version` are untouched. Handed to one other thread. A snapshot is a copy of a World, not the porcelain's `snapshot(scope)` read. | Plain. |
| **`perceive_in`** | The `resolve` parameter that names the frame perceiving the result (WORLD-SERVICE-V1 §7b): the plant, the force (or memo) and a mirror of what resolved into that frame, as `observed` rows through the gate, run in one atomic unit. Only the rows the frame does not already hold are written. | Plain. |
| **view frame** | The frame a `WorldService` serves its viewers: the player's `knows:` frame, given at `attach` and changed with `set_view_frame`. A viewer names no frame; the service injects this one. | Plain. |
| **pump** | The host's call into `WorldService.pump()`, on the thread that attached: it runs the queued owner jobs (viewer resolves, records) and refreshes the viewer snapshot if the committed log head or the classifier's `verdict_version` moved. Pump points are where the host waits for input and after a settle. | Plain. |
| **offline mirror** | The device's copy of the player's view (VIEW-EXPORT-V1): a `patternbuffer.view/1` document (`known` and `present`) built by `patternbuffer.mirror.export` and kept in step by `feed`; the client applies the ops with `apply`, never folds the log. Distinct from `perceive_in`'s mirroring of resolved rows into a frame. | Plain: a mirror is a copy kept in step. |
| **present layer** | The mirror document's drawables of unperceived things in the places the view covers (VIEW-EXPORT-V1 §2): per thing a `kind`, a containment `in` (`[relation, ref]` or `[relation, ref, slot]`), an optional `address`, and declared `look` aspects, all literal JSON scalars under handles. Off (`null`) without a mirror key. Never persons, never meaning. | Plain. |
| **handle** | The keyed, opaque id (`h:` + 20 hex of `HMAC-SHA256(key, world_id NUL canonical_id)`) of an unperceived thing in the present layer (VIEW-EXPORT-V1 §2). `WorldService.unhandle(handle)` and the standalone `record` map a current handle back to its id; nothing else does. | Plain: a handle you hold without seeing what is inside. |
| **people layer** | The offline mirror's opt-in layer of persons' canon whereabouts (`place`, `in`) and the host-named **person facts**, keyed by canonical id (VIEW-PEOPLE-V1). Off by default (no `people` key); `people=` on `export`/`feed`, `--people` on the runner and CLI. For single-player hosts that accept the exposure. | Plain: where the world says the people are. |
| **person facts** | The attributes a host names to cross in the people layer (`posture`, `activity`, ...), normalized once (canonical, deduplicated, sorted) and hashed into the cursor's `q`. Never position, `kind` or bookkeeping attributes. | Plain. |
| **view module** | The `js/patternbuffer/` ES modules (VIEW-JS-V1): the browser port of `mirror.apply` (people layer included), a persisted view (`openView`, IndexedDB, synced through `feed`) and a queued `record` (`openQueue`, at-least-once, `delta` refused). It never folds; Python's `apply` is the reference and the vectors decide. | Plain. |
| **view cursor** | The signed, opaque token a `feed` answers with and is next called with (VIEW-EXPORT-V1 §3): `base64url(body).base64url(mac)`, the body carrying version, world, view frame, frame scope, log head, valid time, a digest of the document and `present_on`. A malformed, foreign, future or stale cursor is answered with a reset. | Plain. |
| **`gated`** | `WorldService.gated(model)`: the pass-through a host injects as its World's model so the service's rate cap can apply, only while a viewer job runs on the owner thread (WORLD-SERVICE-V1 §8). Transparent otherwise. | Plain. |
| **`verdict_version`** | The classifier's in-memory counter, bumped at each verdict write and sidecar rebuild; never stored. With the committed log head it keys the service's snapshot refresh. | Plain. |
| **planted placeholder** | The `generated` placeholder (`value_type: unresolved`, value `{"policy": ..., "planted": "resolve"}`) the resolver appends for a declared, unmarked aspect and forces in the same atomic unit (RESOLVE-UNMARKED-V1), as opposed to one a host planted. Timeless when the aspect's durability pin is `CONSTITUTIVE` or `DISPOSITIONAL`, else at `at` or the scene cursor. The porcelain answers `"planted": true` on the call that planted it. | Plain. |
| **exact decimal / `$decimal`** | An exactly-folding quantity (money, any real ledger): a Python `Decimal` in memory, the reserved tag dict `{"$decimal": "12.50"}` on every JSON boundary (storage, dump, host payloads). Authored scale is preserved in the log, and the stored-row lookup `visible(value=)` is scale-sensitive (`12.50` ≠ `12.5`); a *folded* value match (`where`, `who_knows`, `state(value=)`) is numeric, so `12.5` matches a folded `12.50` (READ-SURFACE-V1 §5). Mixing exact-decimal with float in one fold **raises** (`Decimal`+`int` is fine); fold arithmetic runs under one fixed context (prec=50, HALF_EVEN) for byte-determinism. The tag key is reserved in value-space — only an exact one-key, finite-parseable dict is ever reconstructed, and the porcelain decodes a tag argument before matching. | Standard JSON convention for typed scalars (`$`-prefixed tag). |
| **`route()`** | Passability-aware routing (RFC-003): the structural `path()` graph with each portal segment classified `clear`/`blocked`/`obscured` under the host's declared traversal policy. Two-pass (classify, never delete-then-BFS); returns evidence for blocked, a computed `unknown_basis` for obscured. `path()` stays structural; `route()` owns passability. | Plain navigation vocabulary. |

| **`aka`** | The third, **non-collapsing** identity relation (AKA-CORRELATION-V1) — between `same_as` (collapse) and `distinct_from` (separate). | **correlation group** | The connected component `correlation_set` computes (FRAME-SCOPED-IDENTITY-V1 §3): `aka` edges, each expanded through the canon `same_as` closure. | **`identity_conflicts()`** | Read-only surfacing of merged canon `same_as` closures that hold a pair the guarded merge would veto — a containment-family or `distinct_from` row with both endpoints inside (FRAME-SCOPED-IDENTITY-V1 §4): what a raw or legacy `same_as` merged past the vetoes.
